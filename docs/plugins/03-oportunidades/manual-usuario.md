# Manual del Estudiante — EduTech Oportunidades

## 1. Explorar Convocatorias
1. En la barra lateral de EduTech, ingresar a **Oportunidades** (`/oportunidades`).
2. Utilizar los filtros superiores para acotar por:
   - **Categoría:** Desarrollo de software, Robótica, Telecomunicaciones, Inteligencia Artificial, etc.
   - **Modalidad:** Presencial, Virtual o Híbrida.
   - **Búsqueda libre:** Palabras clave o nombre de empresa/institución.
3. Hacer clic en `Ver Detalle` para revisar objetivos, requisitos técnicos y vacantes disponibles.

## 2. Inscribirse en una Oportunidad
1. En la tarjeta o ficha de detalle, presionar `Postularme`.
2. Completar:
   - Trayectoria o presentación breve.
   - Motivación personal para el proyecto.
   - Conocimientos o herramientas que manejas.
   - Disponibilidad horaria semanal.
3. Presionar `Confirmar Postulación`. Se enviará inmediatamente una notificación al responsable institucional con tus datos de contacto.

## 3. Seguimiento de Postulaciones
1. Ingresar a la pestaña **Mis Postulaciones**.
2. Podrás verificar en tiempo real si tu postulación está:
   - `PENDIENTE DE REVISIÓN`
   - `EN EVALUACIÓN`
   - `CONVOCADO A ENTREVISTA`
   - `ACEPTADO / SELECCIONADO`
   - `NO SELECCIONADO`
3. Si el estado es pendiente, tienes la opción de cancelarla voluntariamente en cualquier momento.
